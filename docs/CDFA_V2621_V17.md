# JEPPIRAN CDFA V1.6 — 16-chart QA V17

Cycle 2621, source original Jeppesen PDF. **Simulation/engineering QA only. Not approved for real-world navigation.**

## New rules
- Use chart-published final approach angle; when absent, label 3° ASSUMED (318 ft/NM).
- Runway threshold elevation first, airport elevation only as clearly marked fallback.
- If TCH missing, use 50 ft but label `DEFAULT_ASSUMED_50_FT_QA`; never replace published TCH even if zero.
- Rows at integer DME increments; computed MDA intercept (VDP) DME to one decimal, never a published VDP.
- Per-chart modeling to D10 / D13 / D15 (as requested). Beyond the chart's published vertical-angle segment: `MODEL_ONLY`.
- When mandatory crossing at D10 and gradient would reach that ALT at a different DME: compute an altitude intersection, but DO NOT move the published mandatory DME fix. The continuous profile remains `BLOCKED_BY_QA`.
- NDB procedure reference remains distinct from numeric supporting DME.
- Station offsets from chart geometry or single altitude are NOT independently surveyed or validated.
