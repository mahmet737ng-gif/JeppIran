X-PLANE 11.5 BRIDGE

X-Plane 11.5 sends UDP, which Safari cannot receive directly. Run the JEPPIRAN X-Plane Bridge on the simulator PC, then connect here using its WebSocket address.

FSX SIMCONNECT BRIDGE

Run JEPPIRAN FSX Bridge v1.3 on the FSX PC. Enter the Windows IPv4 address printed by the bridge. JEPPIRAN stays on its permanent HTTPS address and keeps FSX connected while you use Home, Charts and WX.

Use the actual LAN/hotspot IPv4 address, usually the address on the same network as your iPad. No certificate, profile, or port entry is required.
